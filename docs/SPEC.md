# Спецификация Hermes Neural Council v0.2.0

## Результат

Публичный Hermes Tap с тремя независимыми скиллами:

- `mini-sovet` — один ответ выбранного профиля;
- `spor` — до трёх раундов критики с тем же профилем;
- `consigliere` — интервью, сторож, два независимых веб-ресерча, критика и судья.

Личная версия автора, его база знаний, карточки моделей и серверные пути не
являются зависимостями и не публикуются.

## Договор Consigliere

1. Скилл создаёт приватную папку и проводит интервью по единому списку критериев.
2. `goal.md` и `brief.md` показываются пользователю до первого вызова модели.
3. Один программный сторож проверяет оба файла. Скилл не дублирует его вручную.
4. `НЕ ГОТОВО` останавливает разбор до изменения входов и нового подтверждения.
5. `ГОТОВО` сохраняется с отпечатком входов, критериев и профиля сторожа.
6. Полный запуск требует отдельного подтверждения четырёх вызовов.
7. Два ресерча используют разные профили. Критик может использовать третий.
8. Готовые этапы возобновляются только при неизменных входах и профилях.
9. Судья выдаёт вывод по проблеме, а не обзор работы моделей.

## Профили

- `council-1` и `council-2` обязательны для `consigliere` и должны иметь разные
  имена; программа не может доказать, что внутри действительно разные модели.
- `council-3` необязателен и используется только для критики.
- Имена моделей и уровни рассуждений не зашиваются в публичный код.
- Сторож работает через `council-1`, поэтому не обещается как дешёвый.

## Изоляция

Каждый гость запускается через Hermes с отдельным профилем, `--ignore-rules` и
`--toolsets safe`. Он получает только собранный текст своего этапа. Личная
память, правила, терминал и локальные файлы недоступны; веб-поиск доступен.

## Хранение и защиты

- Папки создаются внутри `$HERMES_HOME/neural-council/` с закрытыми правами.
- `.env`, приватные ключи и типовые токены блокируются до вызова.
- Вход одного файла ограничен 200 000 байт.
- `--dry-run` не вызывает модель.
- Пустой ответ, ошибка и неверный формат сторожа не сохраняются как успех.
- Автоматических повторов нет.
- Изменённые входы запрещают переиспользование старых карт.

## Критерии приёмки

1. Hermes Tap обнаруживает и устанавливает все три скилла.
2. Все пути внутри инструкций используют `${HERMES_SKILL_DIR}`.
3. Подставной Hermes подтверждает профили и `--ignore-rules --toolsets safe`.
4. `НЕ ГОТОВО` не запускает ресерчи.
5. Изменённый бриф перепроверяется; неизменный `ГОТОВО` повторно не тратит вызов.
6. Изменённые входы после готовых карт останавливают прогон.
7. Два ресерча используют разные профили, третий критик остаётся необязательным.
8. Сухой полный запуск показывает четыре предстоящих вызова без модели.
9. Секретоподобные данные блокируются до вызовов.
10. Штатный community-сканер Hermes не выдаёт опасный вердикт.
11. После публикации установка из настоящего GitHub Tap проходит успешно.

## Границы v0.2.0

Нет Windows, локализации, новых этапов, второго сторожа, обязательного третьего
профиля, голосования, автоматических повторов и интеграции с Obsidian.
