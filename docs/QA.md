# Проверка v0.1.0

Дата: 2026-07-22.

## Автоматические тесты

Команда: `python3 -m unittest discover -s tests -v`.

Результат: 9 из 9 тестов прошли. Проверены:

- dry-run без вызова модели;
- обязательное подтверждение;
- сохранение ответа и состояния Mini-sovet;
- блокировка секретоподобного имени и содержимого;
- три раунда Spor, запрет смены профиля и четвёртого раунда;
- сбой без ложного зачёта раунда;
- защита неизменяемого исходного материала;
- идентичность двух собранных скриптов;
- обязательные поля обоих `SKILL.md` и `${HERMES_SKILL_DIR}`.

## Штатный сканер Hermes

Оба пакета проверены `tools.skills_guard.scan_skill` как community-источник.

- `mini-sovet`: verdict `safe`, установка разрешена;
- `spor`: verdict `safe`, установка разрешена.

Единственная находка — ожидаемый `subprocess.run`, которым скилл вызывает
отдельный профиль Hermes. Ложные срабатывания по окружению и слову profile
устранены без обхода сканера.

## Загрузка Hermes

Оба скилла скопированы во временный `HERMES_HOME` и загружены штатным
`skill_view`. Результат для обоих: `success: true`, `readiness_status:
available`; вложенный `scripts/council.py` обнаружен, `${HERMES_SKILL_DIR}`
заменён абсолютным путём.

## Командная строка

Живой `hermes --help` подтвердил наличие `--profile`, `--ignore-rules`,
`--toolsets` и `-z`. Dry-run собрал ожидаемую команду с профилем `council-1` и
набором `safe`.

## Что ещё нельзя проверить до публикации

- добавление настоящего GitHub Tap;
- установка пакета через GitHub Contents API;
- `hermes skills check/update` для опубликованной версии;
- живой ответ модели — требует отдельного профиля, авторизации и расхода лимита.
