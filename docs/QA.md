# Проверка v0.2.0

Дата: 2026-07-29.

## Автоматические тесты

Команда: `python3 -m unittest discover -s tests -v`.

Результат: 22 из 22 тестов прошли. Проверены:

- прежние сценарии `mini-sovet` и `spor`;
- подготовка цели и брифа;
- сторож и повторная проверка после изменения входов;
- запрет продолжения после `НЕ ГОТОВО`;
- два обязательных независимых профиля и отдельный профиль критика;
- сухое превью без вызова модели;
- возобновление готовых этапов и запрет старых карт;
- изоляционные флаги и обезличивание названий моделей;
- соответствие исходников собранным пакетам.

Также успешно выполнены компиляция Python, `git diff --check` и структурная
проверка всех трёх `SKILL.md` штатным валидатором Codex.

## Проверка внутри Hermes Agent v0.18.2

Все три пакета загружены во временный `HERMES_HOME` через штатный `skill_view`.
Результат: `success: true`, `readiness_status: available`; переменная
`${HERMES_SKILL_DIR}` подставлена правильно.

Community-сканер Hermes разрешил все три пакета с вердиктом `safe`. Оставшиеся
находки — только ожидаемые вызовы дочерней команды `hermes` через
`subprocess.run`.

Подготовка папки `consigliere` и сухой запуск сторожа прошли внутри рабочего
Docker-контейнера Hermes. Команда использовала отдельные профили,
`--ignore-rules` и набор инструментов `safe`.
