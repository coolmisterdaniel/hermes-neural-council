# Hermes Neural Council

Два публичных скилла для [Hermes Agent](https://hermes-agent.nousresearch.com/):

| Скилл | Что делает |
|---|---|
| `mini-sovet` | один независимый ответ другого профиля Hermes |
| `spor` | до трёх раундов критики с тем же профилем |

Проект не содержит моделей, API-ключей и личных настроек. Пользователь сам
назначает любую доступную модель отдельному профилю Hermes.

Первая версия поддерживает Linux и macOS. Windows будет добавлен после отдельной
проверки запуска Python в Hermes Desktop.

## Установка

После публикации репозитория:

```bash
hermes skills tap add coolmisterdaniel/hermes-neural-council
hermes skills install coolmisterdaniel/hermes-neural-council/mini-sovet
hermes skills install coolmisterdaniel/hermes-neural-council/spor
```

Затем создайте отдельный профиль и выберите для него модель через обычный мастер
Hermes:

```bash
hermes profile create council-1
hermes --profile council-1 setup
```

Дополнительные слоты называются `council-2`, `council-3` и так далее. Разные
имена профилей могут указывать на одну модель — проверьте настройки, если вам
нужны действительно разные мнения.

В чате используйте `/mini-sovet` или `/spor`, либо попросите естественным языком:
«дерни модель №1» / «обсудите это с моделью №1».

## Что увидит приглашённая модель

- выбранный текстовый файл;
- правила ответа или честной критики;
- в раундах 2–3 — свой прошлый ответ и возражения ведущего.

Гость запускается с `--ignore-rules` и набором инструментов `safe`: без памяти,
личных правил, терминала и доступа к локальным файлам. Веб-поиск остаётся
доступным для проверки фактов.

## Стоимость и приватность

Каждый ответ — отдельный вызов выбранной модели и отдельный расход её лимита.
Перед каждым реальным вызовом скилл обязан показать профиль и получить
подтверждение. Автоматических повторов после ошибки нет.

Материал передаётся поставщику выбранной модели. При включённом веб-поиске часть
запроса может уйти поисковому сервису. Не передавайте секреты и чувствительные
данные. Программа блокирует типовые ключи и файлы вроде `.env`, но такая проверка
не заменяет внимательность человека.

На многопользовательской машине собранный запрос может кратко отображаться в
списке процессов, потому что официальный одноразовый режим Hermes принимает его
аргументом `-z`.

## Где лежат разговоры

По умолчанию: `$HERMES_HOME/neural-council/` или
`~/.hermes/neural-council/`. Файлы создаются с закрытыми правами там, где это
поддерживает ОС. Папку не следует добавлять в Git.

## Разработка и проверка

Проект использует только стандартную библиотеку Python:

```bash
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

Тесты вызывают подставной Hermes и не требуют сети, ключей или модели.

Штатный community-сканер Hermes видит ожидаемый запуск дочерней команды
`hermes`, но итоговый вердикт обоих скиллов — `safe`.

## Обновления

После публикации новых версий:

```bash
hermes skills check
hermes skills update
```

Hermes Tap первой версии поддерживается через публичный GitHub.com. GitLab,
самохостинговый Git и приватные репозитории проект пока не обещает.
