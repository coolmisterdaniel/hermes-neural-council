# Hermes Neural Council

Три публичных скилла для [Hermes Agent](https://hermes-agent.nousresearch.com/):

| Скилл | Что делает | Вызовов моделей |
|---|---|---:|
| `mini-sovet` | один независимый ответ другого профиля | 1 |
| `spor` | до трёх раундов критики с тем же профилем | 1–3 |
| `consigliere` | бриф, сторож, два веб-ресерча, критика и итог | 5 |

Проект не содержит моделей, API-ключей и личных настроек. Пользователь назначает
любые поддерживаемые модели отдельным профилям Hermes. Личная версия автора не
публикуется и не является зависимостью.

Поддерживаются Linux и macOS. Windows отложен до отдельной проверки Python в
Hermes Desktop.

## Установка

```bash
hermes skills tap add coolmisterdaniel/hermes-neural-council
hermes skills install coolmisterdaniel/hermes-neural-council/mini-sovet
hermes skills install coolmisterdaniel/hermes-neural-council/spor
hermes skills install coolmisterdaniel/hermes-neural-council/consigliere
```

Обновления:

```bash
hermes skills check
hermes skills update
```

## Профили моделей

Для `mini-sovet` и `spor` достаточно одного отдельного профиля. Для
`consigliere` обязательны два:

```bash
hermes profile create council-1
hermes --profile council-1 setup

hermes profile create council-2
hermes --profile council-2 setup
```

- `council-1` — сторож, первый ресерч и судья;
- `council-2` — второй ресерч и, по умолчанию, критик;
- необязательный `council-3` — отдельный критик.

Разные названия профилей могут указывать на одну модель. Для действительно
независимых ресерчей проверьте, что `council-1` и `council-2` используют разные
модели или хотя бы разных поставщиков.

## Как работает Consigliere

`Consigliere` нужен не для обычного вопроса, а для сложного решения, которое
дорого переигрывать и где заранее неизвестны все риски.

1. Основной Hermes проводит интервью по пяти критериям и формирует `goal.md` и
   `brief.md`.
2. Сторож проверяет полноту. При `НЕ ГОТОВО` дорогие этапы не запускаются.
3. После отдельного подтверждения два профиля независимо проводят веб-ресерч.
4. Критик разбирает обезличенные карты.
5. Судья выдаёт решение по проблеме, условия, риски и пункты личной проверки.

Интервью входит в скилл, а обязательные защиты реализованы программой. Вердикт
сторожа связан с содержимым цели, брифа, критериев и профиля: после изменения
любого из них нужна новая проверка. Старые карты после изменения входов не
переиспользуются.

## Стоимость

`mini-sovet` и каждый раунд `spor` расходуют один вызов выбранного профиля.

Полный `consigliere` расходует пять вызовов: сторож и четыре этапа разбора. Два
веб-ресерча обычно дают основную часть расхода. Точная стоимость зависит от
моделей, поставщиков и глубины поиска. Перед сторожем и перед четырьмя дорогими
этапами скилл получает отдельные подтверждения; автоматических повторов нет.

## Приватность и изоляция

Гость запускается с `--ignore-rules` и набором инструментов `safe`. В Hermes
Agent v0.18.2 он включает веб-поиск и извлечение страниц, но не терминал и не
локальные файлы.

Материал всё равно отправляется поставщику выбранной модели, а поисковые запросы
— поисковому сервису. Не передавайте секреты и чувствительные данные. Программа
блокирует типовые ключи и файлы вроде `.env`, но запрет помещать личные данные в
поиск остаётся инструкцией модели, а не абсолютной технической гарантией.

Разговоры сохраняются с закрытыми правами в
`$HERMES_HOME/neural-council/` или `~/.hermes/neural-council/`. Эту папку не
следует добавлять в Git.

## Разработка и проверка

Проект использует только стандартную библиотеку Python:

```bash
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

Тесты используют подставную команду Hermes и не требуют сети, ключей или модели.
Они проверяют подтверждения, секреты, спор, сторожа, отпечатки входов, профили,
возобновление этапов и изоляционные флаги.
